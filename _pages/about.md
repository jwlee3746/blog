LLM을 실제 제품에 태우는 일을 합니다. 모델 튜닝·평가뿐 아니라 에이전트 오케스트레이션, 안정적인 도구 실행, 실행 흐름 관측까지 제품 환경의 LLM 시스템을 함께 만듭니다.

## 현재 하는 일

2024년 7월부터 삼성전자 MX사업부 Language AI에서 ML 엔지니어로 일하고 있습니다.

- Bixby LLM 모델을 평가하고, 평가 결과를 바탕으로 프롬프트를 개선합니다.
- 여러 모델 제공자에 공통으로 적용되는 설정 체계 구축을 주도합니다.
- 에이전트 오케스트레이션을 공동 개발하고, 담당 미들웨어를 구현해 도구 실행 안정성을 개선합니다.
- Langfuse·OpenTelemetry 기반 추적 체계 구축을 주도하고 프롬프트·하네스 전략을 함께 구현합니다.

## 이전 프로젝트

### MVM+

학부 산학 연계 인턴으로 metric learning 기반 생성 모델 MVM+를 설계하고 Average Hausdorff loss를 고안했습니다.

### KAIST × 네이버 산학 협력

네이버 쇼핑 이미지 준지도 분류와 검색 스니펫 기반 한국어 QA 모델을 개발했습니다. 두 작업은 [선별 프로젝트]({{ site.baseurl }}/Project/)에서 하나의 산학 협력 묶음으로 정리했습니다.
